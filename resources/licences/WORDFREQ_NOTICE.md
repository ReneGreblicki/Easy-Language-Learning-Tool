# wordfreq data strategy

The release frequency lists are derived at build time with `wordfreq` and language-specific POS/lemma tooling. `wordfreq` code is Apache-2.0 and its redistributable data includes CC BY-SA 4.0 and separately attributed sources. The complete upstream NOTICE must accompany any derived release resource.

Source: https://github.com/rspeer/wordfreq

The application does not export raw frequency lists. User workbooks contain only selected words used for generated learning material; internal metadata records rank.
